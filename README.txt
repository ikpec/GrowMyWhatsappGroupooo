GrowMyWhatsAppGroup website (standalone files)

FILES
- index.html: homepage
- signup.html: demo sign-up
- login.html: demo login
- dashboard.html: group request form and WhatsApp handoff

HOW TO TEST
1. Open index.html in a browser or publish these files using GitHub Pages.
2. Choose Get started and create a demo account.
3. Fill in your WhatsApp group link, what the group is about, target members needed, and optional extra details.
4. Tap Review request, check the preview, then tap Send request to WhatsApp.
5. WhatsApp opens a message addressed to 08161390587 (international format +2348161390587). Press Send inside WhatsApp.

IMPORTANT LIMITATION
This is a static front-end prototype. Demo account details are stored in the same browser using localStorage; accounts do not sync between devices or browsers. This is not secure production authentication and should not be used with real/reused passwords. GitHub Pages cannot run a PHP/database backend. For a public production service with secure accounts and centrally stored requests, a backend/database must be added.
All files are in one folder; no css/ or js/ subfolders are needed.
